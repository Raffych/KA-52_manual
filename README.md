## 📖 О проекте

Это одностраничное веб-приложение (SPA), которое предоставляет интерактивный справочник по функциям рации КА-52. Приложение включает:

- **Интерактивную клавиатуру** с отображением функций кнопок для разных режимов
- **Справочник меню** с поиском и фильтрацией
- **Параметры спектроанализатора**
- **Детальный мониторинг регистров**
- **Чек-листы** для работы с UV TOOL на ПК

Приложение оптимизировано для мобильных устройств и работает полностью в браузере без необходимости серверной части.

## 📊 Детальное описание разделов

### 1. Клавиатура (tab-keyboard)

**Расположение в коде:** HTML строки 128-143, JavaScript строки 197-280

**Функционал:**
- Интерактивная клавиатура 4×4
- Переключатель режимов: MR, VFO, Спектр, FM Радио
- Контекстная информация для каждого режима
- Модальное окно с детальной информацией по кнопкам

**Режимы работы:**
- **MR (Memory Mode)** — канальный режим
- **VFO (Variable Frequency Oscillator)** — режим прямой настройки частоты
- **SPECTRUM** — режим спектроанализатора
- **FM** — режим радиоприёмника

### 2. Меню (tab-menu)

**Расположение в коде:** HTML строки 146-157, JavaScript строки 282-300

**Функционал:**
- Поиск по названию, коду или ID
- Фильтрация по категориям
- Карточки с раскрывающимся описанием

**Категории меню:**
- Связь
- Аудио
- Дисплей
- Безопасность
- Калибровка

### 3. Спектр (tab-spectrum)

**Расположение в коде:** HTML строки 159-163, JavaScript строки 302-312

**Функционал:**
- Параметры спектроанализатора
- Навигационные подсказки

### 4. Мониторинг (tab-monitoring)

**Расположение в коде:** HTML строки 165-169, JavaScript строки 314-324

**Функционал:**
- Детальный мониторинг регистров (MENU → M^A)
- Низкоуровневые параметры приёмника

### 5. Чек-листы (tab-guides)

**Расположение в коде:** HTML строки 171-183, JavaScript строки 326-330

**Функционал:**
- Пошаговые инструкции с чекбоксами
- Три типа руководств:
  - Прошивка (flash)
  - Сброс (reset)
  - Каналы (channels)

## ✏️ Как вносить изменения

### Изменение данных клавиатуры

**Местоположение:** Объект `keyData` (строки 206-280)

**Структура:**
```javascript
const keyData = {
  MR: {           // Режим (MR, VFO, SPECTRUM, FM)
    '1': {        // Кнопка
      s: 'Набор',                    // Простое нажатие (short)
      l: 'Перенос частоты в VFO',    // Долгое нажатие (long)
      f: '1CALL',                    // После F (function)
      full: 'Подробное описание...'  // Полное описание для модального окна
    },
    // ... другие кнопки
  },
  // ... другие режимы
};
```

**Пример добавления новой функции кнопки:**
```javascript
'5': {
  s: 'Список сканир.',
  l: 'Новая функция L',
  f: 'Новая функция F',
  full: '1 – Простое нажатие.\nL5 – Новая функция долгое.\nF5 – Новая функция после F.'
}
```

**Важно:**
- Используйте `\n` для переноса строк в поле `full`
- Все 4 режима должны иметь определения для всех кнопок
- Кнопки: `M`, `<`, `>`, `Exit`, `1-9`, `0`, `*`, `#F`

### Изменение пунктов меню

**Местоположение:** Массив `menuItems` (строки 282-332)

**Структура:**
```javascript
{
  id: 1,                              // Номер пункта меню (1-50)
  code: "Step",                       // Код меню
  title: "Шаг частоты",               // Заголовок
  desc: "Описание...",                // Подробное описание
  vals: ["0.01", "0.05", "..."],     // Возможные значения
  cat: "Связь",                       // Категория
  warn: "⚠️ Предупреждение"          // Опционально: предупреждение
}
```

**Пример добавления нового пункта меню:**
```javascript
{id: 51, code: "NewFunc", title: "Новая функция", desc: "Описание новой функции", vals: ["ON", "OFF"], cat: "Связь"}
```

**Категории:**
- `"Связь"`
- `"Аудио"`
- `"Дисплей"`
- `"Безопасность"`
- `"Калибровка"`

### Изменение чек-листов

**Местоположение:** Объект `guides` (строки 382-390)

**Структура:**
```javascript
const guides = {
  flash: [                          // Тип руководства
    {t: "Шаг 1"},                   // t = text (текст шага)
    {t: "Шаг 2"},
    // ...
  ],
  reset: [
    {t: "Выключите рацию"},
    // ...
  ],
  channels: [
    {t: "Включите рацию"},
    // ...
  ]
};
```

**Пример добавления нового шага:**
```javascript
flash: [
  {t: "Вкл. рацию в режиме прошивки (PTT + включение)"},
  {t: "Новый дополнительный шаг"},
  {t: "Подготовьте кабель USB-C с передачей данных"},
  // ...
]
```

**Для добавления нового типа руководства:**
1. Добавьте новый массив в объект `guides`:
```javascript
newguide: [
  {t: "Шаг 1"},
  {t: "Шаг 2"}
]
```

2. Добавьте кнопку в HTML (строка 173-177):
```html
<button class="mode-btn" onclick="showGuide('newguide')">Новое руководство</button>
```

3. Добавьте контейнер (после строки 182):
```html
<div id="guide-newguide" class="guide-content" style="display:none;">
  <ul class="checklist" id="checklist-newguide"></ul>
</div>
```

4. Обновите функцию `renderGuides()` (строка 390):
```javascript
function renderGuides(){
  ['flash','reset','channels','newguide'].forEach(k=>{
    document.getElementById('checklist-'+k).innerHTML=guides[k].map((g,i)=>
      `<li onclick="toggleCheck(this)">
        <span class="step-num">${i+1}</span>
        <input type="checkbox" onchange="checkStep(this)">
        <span>${g.t}</span>
      </li>`
    ).join('');
  });
}
```

## 🔧 Технические детали

### Зависимости

Единственная внешняя зависимость — шрифт Inter:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fontsource/inter@5.0.18/index.min.css">
```

### Совместимость

- Современные браузеры (Chrome, Firefox, Safari, Edge)
- Мобильные браузеры (iOS Safari, Chrome Android)
- Минимальная ширина экрана: 320px

### Архитектура

**Модульная структура JavaScript:**
- `setupNavigation()` — инициализация навигации
- `setupModeSwitcher()` — переключатель режимов
- `setupFilters()` — фильтры меню
- `renderKeypad()` — рендеринг клавиатуры
- `renderMenu()` — рендеринг меню
- `renderSpectrum()` — рендеринг спектра
- `renderMonitoring()` — рендеринг мониторинга
- `renderGuides()` — рендеринг чек-листов
- `showKeyModal()` / `closeKeyModal()` — модальные окна
- `filterMenu()` — фильтрация меню
- `showGuide()` — переключение руководств
- `toggleCheck()` / `checkStep()` — чекбоксы
- `showToast()` — уведомления

### Хранение данных

Все данные хранятся непосредственно в JavaScript-объектах внутри HTML-файла:
- `keyData` — функции кнопок
- `menuItems` — пункты меню
- `specParams` — параметры спектра
- `monitoringParams` — параметры мониторинга
- `guides` — чек-листы
- `contextInfo` — контекстные подсказки

### Производительность

- Отсутствие внешних зависимостей (кроме шрифта)
- Минимальный размер файла (~47KB)
- Быстрая загрузка и отклик
- CSS-анимации вместо JavaScript для плавности
